# 🍜 Which Soto Are You? (你是哪一種梭多？)

> **Culture Salon Presentation — Indonesian Soto Quiz**
> An interactive bilingual (English / 繁體中文) personality quiz exploring 5 iconic regional varieties of Indonesian Soto.

![Which Soto Are You Hero](https://images.unsplash.com/photo-1541832676-9b763b0239ab?w=1000&auto=format&fit=crop&q=80)

---

## 🌟 Features

- 🌐 **Instant Bilingual Toggle (EN ⇄ 繁體中文):** Seamless switching across all questions, options, blurbs, and fun facts.
- 📱 **Mobile-First & Presentation Ready:** Responsive design optimized for smartphone screens during live talks.
- 🎨 **Cute Duolingo-Style Vector Art:** 5 distinct animated soto bowl characters with rising steam.
- 🗺️ **Interactive Indonesian Archipelago Map:** Visualizes each soto's regional origin (Java, Sumatra, Kalimantan, Sulawesi) with pulsating location pins.
- 📊 **BuzzFeed-Style Scoring Logic:** 8 questions with a dedicated tie-breaker decider (Question 8: Travel style).
- 🔊 **Synthesized Web Audio Effects:** Chopstick tap, soup bubble pop, and celebration fanfare (with mute switch).
- 🎊 **Celebratory Confetti Burst:** Visual reward upon revealing your soto personality.
- 📱 **Built-in Presentation QR Code:** One-click projection modal for classroom scanning.

## 🍲 The 5 Soto Personalities

1. 🟡 **Soto Ayam Lamongan** (East Java) — *The Reliable Classic / 值得信賴的經典款*
2. 🔴 **Soto Betawi** (Jakarta) — *The Indulgent Comfort-Seeker / 極致享受的生活家*
3. 🟠 **Soto Padang** (West Sumatra) — *The Bold Adventurer / 大膽無畏的探險者*
4. 🔵 **Soto Banjar** (South Kalimantan) — *The Refined Old Soul / 低調優雅的老靈魂*
5. 🟢 **Coto Makassar** (South Sulawesi) — *The Daring Original / 獨樹一幟的先鋒派*

## 🚀 Deployment via GitHub Pages

1. Push this repository to GitHub under your account (`ClarissaDyan`):
   ```bash
   git remote add origin https://github.com/ClarissaDyan/Culture-Salon-Soto-Quiz.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** → **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch: `main` and folder: `/ (root)`.
   - Click **Save**.
3. Your live quiz link will be active at:
   `https://clarissadyan.github.io/Culture-Salon-Soto-Quiz/`
